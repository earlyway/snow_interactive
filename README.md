# Marshmallow Pile

카메라 앞 손동작으로 즐기는 웹 인터랙티브. 화면 아래에 2.5D 마시멜로(조명을 받는 둥근 원기둥 인스턴스)가 쌓여 있고, 멜로우봇 3D 모델이 그 위에 튜브처럼 떠 있습니다. 손을 내밀어 마시멜로를 누르면 Live2D 식 메시 변형으로 젤리처럼 출렁이고, 멜로우봇을 밀거나 눌러 자유롭게 굴릴 수 있습니다. 마시멜로 높이는 슬라이더로 조절합니다.

- 빌드 없이 정적 파일만으로 동작 (three.js + MediaPipe, CDN 로드)
- 카메라 영상은 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다
- 카메라가 없으면 마우스가 손 역할을 합니다
- 이전 버전(핫초코 비 · 손 흡입)은 git 이력 `9356f68` 에 있습니다

## 마시멜로 표현

기본은 **2.5D 모드**: 둥근 원기둥 마시멜로를 인스턴스로 줄지어 쌓고, 전체 더미가 높이에 따라 통째로 오르내립니다. 각 마시멜로는 젤리 격자의 변위를 받아 위치가 밀리고 기울어지며 살짝 찌부러집니다. 설정 패널에서 **2D 이미지 모드**로 바꾸면 아래 이미지를 텍스처 평면으로 씁니다.

### 2D 이미지 모드

`assets/marshmallow.png` 를 두면 그 이미지를 씁니다 (투명 배경 PNG 권장, 2048px 초과는 자동 축소). 파일이 없으면 캔버스로 그린 기본 마시멜로 그림을 사용하고, 설정 패널의 "마시멜로 이미지 바꾸기" 로 실행 중에도 교체할 수 있습니다.
이미지는 세로로 레이어 높이에 맞춰지고 가로로는 원본 비율을 지켜 반복됩니다. 위쪽 투명 여백은 자동 분석해서, 보이는 마시멜로 윗선이 멜로우봇의 부력 기준면에 오도록 메시를 늘립니다.

## 빠른 시작

**macOS:** `start.command` 를 더블클릭하면 로컬 서버를 띄우고 Chrome 을 자동으로 엽니다. 카메라 권한을 허용하면 바로 손으로 조작할 수 있습니다. 터미널 창을 닫으면 서버가 종료됩니다.
처음 실행할 때 macOS 가 Terminal 의 폴더 접근 권한을 물으면 허용해 주세요. `LEVEL=2 ./start.command` 처럼 시작 높이(0~9)를 바꿀 수 있습니다.

**직접 서버 띄우기 (모든 OS):**

```bash
python3 -m http.server 5173
# http://localhost:5173/?autostart=1   (Chrome / Edge 권장)
```

카메라(getUserMedia)는 `https` 또는 `localhost` 에서만 켜집니다. `index.html` 을 파일로 직접 열면 마우스 모드만 동작합니다.
`?autostart=1` 을 붙이면 카메라 권한을 바로 요청하고, `?level=3` 으로 시작 높이를 정할 수 있습니다 (기본 3).

## 조작

| 입력 | 효과 |
|---|---|
| 손 (카메라) | 손이 마시멜로에 닿으면 닿은 부분의 격자 정점이 손 반대쪽으로 밀리고 손 속도를 받아 출렁입니다. 손을 떼면 스프링으로 되돌아옵니다. 손이 윗면 근처에 있으면 파문도 눌려 멜로우봇이 살짝 기울어집니다. |
| 손 → 멜로우봇 | 손이 멜로우봇에 닿으면 밀려납니다. 위에서 누르면 잠기고 손을 떼면 부력으로 튀어 오르며, 친 지점과 방향에 따라 3축으로 회전한 뒤 서서히 바로 섭니다. 화면 밖으로는 나가지 않습니다. |
| 마우스 | 카메라가 없을 때 손 대신 동작합니다. |
| 설정 패널 (우상단) | 마시멜로 높이 · 탄성 · 감쇠 · 손 출렁임 세기, 손/멜로우봇 파라미터, 마시멜로 치우기/쌓기, 이미지 교체, 디버그 오버레이(젤리 격자 표시) |
| 비 (선택) | 기본은 꺼져 있습니다. "초당 방울 수" 를 올리거나 커스텀 비 에셋을 적용하면 방울이 내려 마시멜로 위에서 튑니다. PNG / JPG / SVG / GLB 를 드래그하면 그 모양으로 내립니다. |

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업, 스타일, importmap |
| `app.js` | 레이어 조립, 파라미터 UI, 에셋 업로드 파이프라인, 메인 루프, FPS 기반 자동 스케일링 |
| `tracking.js` | 입력 레이어. 카메라 → MediaPipe 손 랜드마크 → `Interactor { x, y, vx, vy, radius, strength }`. 마우스 fallback |
| `sim.js` | 시뮬레이션 레이어. 마시멜로 높이 + 1D 파문 + 2D 젤리 격자(160×7 스프링), 멜로우봇 부력 강체(쿼터니언 자유 회전), (선택) 비 파티클 풀 |
| `render.js` | 렌더 레이어. 2.5D 마시멜로 InstancedMesh(젤리 변위로 위치·기울기), 2D 텍스처 격자 메시, 멜로우봇 GLB, 에셋별 InstancedMesh, 조명 |
| `assets.js` | 에셋 레이어. 이미지/GLB → 파티클 지오메트리 (마스크 · 외곽 추적 · 압출 · 데시메이션), 기본 마시멜로 텍스처 |
| `assets/` | 멜로우봇 GLB, (선택) `marshmallow.png` |
| `samples/` | 커스텀 에셋 테스트용 샘플 (cube, snowman, sphere GLB, dot PNG) |

각 레이어는 위 표의 인터페이스로만 소통합니다. 입력 장치를 바꾸려면 `tracking.js` 만, 물리를 바꾸려면 `sim.js` 만 수정하면 됩니다.

### 시뮬레이션 요약

- **높이 · 파문**: 평균 높이 `level` 과 폭 방향 160 빈의 윗면 변위 `wave` 로 기준면을 표현합니다. 멜로우봇이 오르내리거나 손이 윗면을 누르면 스프링 격자 파동으로 파문이 퍼집니다. 이 기준면이 멜로우봇 부력의 기준입니다.
- **젤리 격자 (Live2D 식 변형)**: 160×7 정점의 변위 `dx, dy` 를 정지 위치로 되돌리는 스프링 + 이웃 결합(라플라시안) + 감쇠로 적분합니다. 행 0 은 바닥에 고정, 위로 갈수록 크게 움직입니다. 손 반경 안의 정점은 손 반대 방향으로 밀리고 손 속도의 일부를 받습니다. 렌더는 텍스처 격자 메시의 정점을 이 위치로 옮깁니다.
- **멜로우봇**: 잠긴 비율로 부력을 계산해 약 1/3 잠긴 상태가 평형입니다. 손 접촉점과 힘의 외적으로 3축 토크가 들어가고, 부력 복원 토크가 서서히 위·정면으로 되돌립니다. 마시멜로 메시가 alphaTest + depth 로 불투명 부분에서 잠긴 몸통을 가립니다.

## 파라미터

설정 패널에서 실시간으로 조절할 수 있고, 콘솔에서 `mallow.P` 로도 접근할 수 있습니다.

| 그룹 | 항목 |
|---|---|
| 마시멜로 | 2.5D / 2D 모드, 높이, 탄성(되돌아오는 힘), 감쇠, 손 출렁임 세기 |
| 손 · 멜로우봇 | 손 반경, 미는 힘, 회전 민감도, 바로 서는 힘, 무게, 트래킹 fps |
| 비 (선택) | 초당 방울 수, 파티클 양, 중력, 바람, 흔들림, 크기, 3D 에셋 텀블링, 스플래시, 방울이 쌓여 높이는 양 |

## 요구 사항

- Chrome 또는 Edge 최신 버전 (WebGL 2, importmap, getUserMedia)
- 웹캠 (없으면 마우스 모드)
- 인터넷 연결 (three@0.160, @mediapipe/tasks-vision@0.10.14 및 손 인식 모델을 CDN 에서 로드)
