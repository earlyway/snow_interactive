# Hot Chocolate Rain

카메라 앞 손동작으로 즐기는 웹 인터랙티브. 핫초코 비가 내려 화면 아래에 차오르고, 멜로우봇 3D 모델이 튜브처럼 수면에 떠오릅니다. 손을 내밀면 떨어지는 방울과 고인 핫초코가 손으로 빨려 들어가고, 멜로우봇을 밀거나 눌러 자유롭게 굴릴 수 있습니다.

- 빌드 없이 정적 파일만으로 동작 (three.js + MediaPipe, CDN 로드)
- 카메라 영상은 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다
- 카메라가 없으면 마우스가 손 역할을 합니다

## 빠른 시작

**macOS:** `start.command` 를 더블클릭하면 로컬 서버를 띄우고 Chrome 을 자동으로 엽니다. 카메라 권한을 허용하면 바로 손으로 조작할 수 있습니다. 터미널 창을 닫으면 서버가 종료됩니다.
처음 실행할 때 macOS 가 Terminal 의 폴더 접근 권한을 물으면 허용해 주세요. `LEVEL=2 ./start.command` 처럼 시작 수위(0~9)를 바꿀 수 있습니다.

**직접 서버 띄우기 (모든 OS):**

```bash
python3 -m http.server 5173
# http://localhost:5173/?autostart=1   (Chrome / Edge 권장)
```

카메라(getUserMedia)는 `https` 또는 `localhost` 에서만 켜집니다. `index.html` 을 파일로 직접 열면 마우스 모드만 동작합니다.
`?autostart=1` 을 붙이면 핫초코가 조금 고인 상태로 시작하며 카메라 권한을 바로 요청하고, 없이 열면 빈 화면과 "카메라 허용" 버튼으로 시작합니다.

## 조작

| 입력 | 효과 |
|---|---|
| 손 (카메라) | 손바닥 주변의 방울이 손으로 끌려 들어가 사라집니다. 손을 수면 가까이 내리면 고인 핫초코가 솟아올라 손으로 빨려가고 수위가 내려갑니다. 펼친 손은 넓고 약하게, 주먹은 좁고 세게 빨아들입니다. |
| 손 → 멜로우봇 | 손이 멜로우봇에 닿으면 밀려납니다. 위에서 누르면 잠기고 손을 떼면 부력으로 튀어 오르며, 친 지점과 방향에 따라 3축으로 회전한 뒤 서서히 바로 섭니다. 화면 밖으로는 나가지 않습니다. |
| 마우스 | 카메라가 없을 때 손 대신 동작합니다. |
| 설정 패널 (우상단) | 비 · 핫초코 · 손 흡입/멜로우봇 파라미터, 핫초코 비우기/채우기, 디버그 오버레이 |
| 커스텀 에셋 | PNG / JPG / SVG / GLB 를 드래그하면 그 모양이 비처럼 내립니다. 이미지는 빌보드(티어 1) 또는 2.5D 압출(티어 2)로 변환되고, GLB 는 폴리 예산에 맞춰 자동 데시메이션됩니다. |

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 마크업, 스타일, importmap |
| `app.js` | 레이어 조립, 파라미터 UI, 에셋 업로드 파이프라인, 메인 루프, FPS 기반 자동 스케일링 |
| `tracking.js` | 입력 레이어. 카메라 → MediaPipe 손 랜드마크 → `Interactor { x, y, vx, vy, radius, strength }`. 마우스 fallback |
| `sim.js` | 시뮬레이션 레이어. 파티클 풀(고정 스텝), 액체 수위 + 1D 파동, 손 흡입, 멜로우봇 부력 강체(쿼터니언 자유 회전) |
| `render.js` | 렌더 레이어. 에셋별 InstancedMesh, 액체 스트립 메시, 멜로우봇 GLB, 조명 |
| `assets.js` | 에셋 레이어. 이미지/GLB → 파티클 지오메트리 (마스크 · 외곽 추적 · 압출 · 데시메이션) |
| `assets/` | 멜로우봇 GLB |
| `samples/` | 커스텀 에셋 테스트용 샘플 (cube, snowman, sphere GLB, dot PNG) |

각 레이어는 위 표의 인터페이스로만 소통합니다. 입력 장치를 바꾸려면 `tracking.js` 만, 물리를 바꾸려면 `sim.js` 만 수정하면 됩니다.

### 시뮬레이션 요약

- **액체**: 평균 수위 `level` 과 폭 방향 160 빈의 수면 변위 `wave` 로 표현합니다. 방울이 닿으면 크기에 비례해 수위가 오르고(`fill`, 상한 `maxLevel`), 스프링 격자 파동으로 파문이 퍼지며, 착지 시 작은 파편이 튑니다.
- **흡입**: 손 반경 안의 방울은 중심 방향으로 가속(가까울수록 강함)되고 코어에 닿으면 흡수됩니다. 손이 수면에서 `suckReach` 안에 있으면 손 아래 수면에서 방울이 `drawRate` 개/초로 솟아오릅니다.
- **멜로우봇**: 잠긴 비율로 부력을 계산해 약 1/3 잠긴 상태가 평형입니다. 손 접촉점과 힘의 외적으로 3축 토크가 들어가고, 부력 복원 토크가 서서히 위·정면으로 되돌립니다. 액체 메시가 depth 를 써서 잠긴 부분을 가립니다.

|---|---|
| 비 | 파티클 양, 초당 방울 수, 중력, 바람, 흔들림, 크기, 3D 에셋 텀블링, 스플래시 |
| 핫초코 | 차오르는 속도, 최대 수위, 줄어드는 속도 |
| 손 흡입 · 멜로우봇 | 흡입 반경/세기, 수면에서 끌어올리는 거리, 끌어올리는 방울/초, 미는 힘, 회전 민감도, 바로 서는 힘, 무게, 트래킹 fps |

## 요구 사항

- Chrome 또는 Edge 최신 버전 (WebGL 2, importmap, getUserMedia)
- 웹캠 (없으면 마우스 모드)
- 인터넷 연결 (three@0.160, @mediapipe/tasks-vision@0.10.14 및 손 인식 모델을 CDN 에서 로드)
